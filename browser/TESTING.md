# Agent Browser — Manual Test Checklist

> **Автоматически:** `npm run test:e2e` гоняет все 38 тулз (+3 необъявленные) в настоящем
> headless Chromium с загруженным расширением и проверяет результат по самой странице
> (`tests/e2e/`). Починенные баги закрыты регрессами; оставшиеся (persistent UA / изоляция профилей) помечены `todo` как out-of-scope. Руками остаётся то, что зависит от модели
> и UI: разделы 6, 8, 10, 11 и промпты «как их поймёт агент».

Открыть side panel в Edge/Chrome → для каждой тулзы написать промпт → проверить результат.
Модель: **Haiku 4.5** (быстрая, дешёвая).

| # | Действие | Ожидаемый результат |
