# Agent Browser — Manual Test Checklist

> **Автоматически:** `npm run test:e2e` гоняет все 38 тулз (+3 необъявленные) в настоящем
> headless Chromium с загруженным расширением и проверяет результат по самой странице
> (`tests/e2e/`). Починенные баги закрыты регрессами; оставшиеся (persistent UA / изоляция профилей) помечены `todo` как out-of-scope. Руками остаётся то, что зависит от модели
> и UI: разделы 6, 8, 10, 11 и промпты «как их поймёт агент».

Открыть side panel в Edge/Chrome → для каждой тулзы написать промпт → проверить результат.
Модель: **Haiku 4.5** (быстрая, дешёвая).

## 10. Remote — телефон и Telegram (кнопка 🛰, без VS Code)

Бот — отдельный, не тот, что крутит Remote в VS Code (один бот читает одна программа).
Логика бота покрыта `tests/telegramBot.test.mjs`; руками — живой Telegram и телефон.

| # | Действие | Ожидаемый результат |
|---|----------|---------------------|
| 10.1 | 🛰 без настроек | Открывается страница настроек на разделе «Remote» |
| 10.2 | Режим «Telegram chat»: токен бота + свой user id → Save → 🛰 | 🛰 светится, в панели «Remote ON — message @бот…» |
| 10.3 | Написать боту задачу | Пузырь в панели, агент работает; ответ в Telegram одним сообщением, обновляется по ходу |
| 10.4 | Режим Careful → задача с кликом | В Telegram «🔐 Allow: click…» с кнопками; Allow → агент кликает |
| 10.5 | `/chats` → выбрать чат, `/new`, `/stop` | Панель переключает чат / новый чат / останавливает задачу |
| 10.6 | Написать боту с чужого аккаунта | Тишина, в панели ничего |
| 10.7 | Закрыть панель, написать боту, открыть панель | Старое сообщение НЕ выполняется |
| 10.8 | Режим «Telegram + web app» (хелпер установлен) → 🛰 | В панели ссылка https://….trycloudflare.com/app?…; бот шлёт «Agent Browser connected» |
| 10.9 | Открыть ссылку / Mini App на телефоне | Полный UI чата, стрим живой, Stop и Allow работают, промпт с телефона доходит |
| 10.10 | Два окна Chrome, в обоих открыта панель | Remote работает в одном; закрыть его панель — подхватывает другое |
| 10.11 | Повторно 🛰 | Всё гаснет (в режиме хелпера — relay, туннель и бот останавливаются) |
