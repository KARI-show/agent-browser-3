Privacy Policy

Effective: October 15, 2026

Overview

Tali is a browser extension that connects you to an AI assistant for browser automation. It runs locally in your browser. The only network traffic it generates is to the AI service you select in the settings.

What data leaves your browser

The extension operates in one of three modes. Each mode has a different data path:

Free trial — Your messages and page content the agent reads are sent to our hosted gateway, which forwards them to the AI provider (Anthropic) for processing. The gateway enforces rate limits and authenticates your session. We do not store or log conversation content. We store your email address (for sign-in) and usage counters (for rate limiting). All traffic is encrypted in transit (TLS).

Your API key — Your messages go directly from the extension to the Anthropic API (or a custom endpoint you configure). No data passes through our servers. Your API key is stored in the browser's local extension storage and is only ever sent to the configured API address.

Claude subscription — Your messages are processed by a local helper application on your computer, which uses your own Claude Code sign-in. No data leaves your machine through our infrastructure. The extension never accesses or stores your Claude login credentials.

If you enable Telegram remote control, messages are also exchanged through the Telegram Bot API with a bot you create and control. The optional relay server is either local or self-hosted.

What is stored locally

  • Chat history and conversation state
  • Your settings: chosen mode, API key (protected by Chrome's extension storage encryption), proxy configuration, Telegram bot token
  • Device profiles: browser identity strings, device configurations, saved cookies, proxy credentials
  • Recipes: recorded automation steps with page element references
  • Watchers: URLs being monitored and detected change snapshots
  • Site memory: notes the agent saved about specific websites

All data is stored in your browser profile's local storage. Removing the extension deletes all of it.

What we do not collect

  • No analytics, telemetry or usage tracking
  • No browsing history
  • No page content beyond what the agent reads at your request during a conversation
  • No cookies or credentials except those you explicitly save in a device profile
  • No device fingerprinting
  • No advertising identifiers or tracking pixels

Third-party services

Depending on the mode you choose, the extension communicates with:

  • Anthropic — the AI provider that processes prompts and generates responses. See Anthropic's privacy policy.
  • Telegram — only if you enable remote control via Telegram. See Telegram's privacy policy.

No other third-party services receive data from the extension.

Security measures

  • Strict Content Security Policy: no remote scripts, images, frames or form submissions from extension pages
  • Sensitive tools (cookie access, JavaScript execution, network capture) require explicit user approval in every mode, including fully automated Agent mode
  • The AI is instructed to treat page content as untrusted and to confirm before payments, account changes, data deletion or sending messages on your behalf
  • No shell or filesystem access — the agent can only use browser tools
  • WebRTC is restricted while a proxy is active to prevent IP address leaks

Age restriction

Tali is not intended for users under 13 years of age. We do not knowingly collect personal information from children.
