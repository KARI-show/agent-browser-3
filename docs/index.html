Privacy Policy

Last updated: October 15, 2026

What Agent Browser is

Agent Browser is a Chrome/Edge extension that lets you interact with an AI assistant (Claude by Anthropic) through a side panel in your browser. The agent can read pages, click elements, fill forms and automate tasks — all within your local browser session.

Data that leaves your browser

The extension sends data only to the AI service you choose in the settings:

  • Free trial mode: your messages and page content the agent reads are sent to our gateway (api.cloud-full.com), which forwards them to the Anthropic API. We do not store conversation content. We store your email address (for sign-in) and usage counters (for rate limiting).
  • API key mode: your messages go directly to api.anthropic.com (or the custom endpoint you configure). The extension communicates only with that endpoint. Your API key is stored locally in the browser's extension storage and is sent only to the configured API address.
  • Subscription mode: your messages go through the local native helper, which uses your own signed-in Claude Code CLI. Nothing is sent to any third-party server.

If you enable Telegram remote, your messages are also sent through the Telegram Bot API to your personal bot. The relay (if used) is either local or one you host yourself.

Data stored locally

  • Chat history (in chrome.storage.local and, for the native helper, ~/.agent-browser/state.json)
  • Settings: chosen mode, API key (encrypted at rest by Chrome), proxy configuration, Telegram bot token
  • Device profiles: User-Agent strings, device templates, saved cookies, proxy credentials
  • Recipes: recorded automation steps with element locators
  • Watchers: monitored page URLs and change snapshots
  • Site memory: notes the agent saved about specific hosts

All local data stays in your browser profile. Uninstalling the extension deletes it.

Data we do NOT collect

  • No analytics or telemetry
  • No browsing history
  • No page content beyond what the agent reads when you ask it to
  • No cookies or credentials beyond what you explicitly save in a device profile
  • No fingerprinting of your device
  • No advertising or tracking

Third-party services

  • Anthropic API (api.anthropic.com) — processes your prompts and page content when the agent runs. Subject to Anthropic's privacy policy.
  • Telegram Bot API — only if you enable remote access via Telegram. Subject to Telegram's privacy policy.

Security

  • The extension's Content Security Policy blocks remote scripts, images, frames and form submissions from extension pages
  • Five tools that access session data (cookies, JavaScript execution, network capture) require explicit user approval, even in fully automated Agent mode
  • The system prompt instructs the model to treat page content as untrusted data and to ask before payments, account changes, sending messages or deleting data
  • The agent has no shell or filesystem access — built-in tools are limited to browser actions
  • WebRTC is restricted while a proxy is active to prevent IP leaks

Children

Agent Browser is not directed at children under 13. We do not knowingly collect personal information from children.
